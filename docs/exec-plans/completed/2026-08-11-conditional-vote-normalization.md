# VOTE-NORMALIZATION-01: Условная нормализация весов MTL

## Контекст
- Степенная нормализация сейчас применяется к любому распределению, даже когда
  доля крупнейшего участника уже меньше 40%.
- На текущем распределении базовые веса с суммой 109 раздуваются до суммы 304,
  а целевая доля крупнейшего участника всё равно не достигается.
- Согласованное правило: базовый расчёт сохраняется без изменений при доле
  крупнейшего не более 40%; нормализация до примерно 33.5% запускается только
  при превышении 40%.

## Риски и открытые вопросы
- Округление вверх сохраняет сумму весов немного выше 100; это согласованное
  поведение, необходимое для минимального веса 1.
- Для экстремальных распределений нормализация остаётся best effort, как и до
  изменения.

## Верификация
- Регрессия: веса для текущего распределения совпадают с первичным расчётом и
  заканчиваются единицей.
- Доминирующий участник после нормализации имеет долю от 33% до 40%.
- Полный набор тестов и статических проверок проходит без ошибок.
